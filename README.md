# PiRadar Core

Public market-data feed and experimental market-scanner runtime within the PiRadar project.

> **Status:** An automated publisher is configured in GitHub Actions and recent snapshot commits have been observed. This is **not** a public guarantee of continuous availability, trading signals, or investment performance.

## Repository scope

| Path | Purpose |
| --- | --- |
| `public/feed/now.json` | Published market-data snapshot, which may be delayed or incomplete |
| `out/priceSnapshot.json` | Snapshot generated by the scheduled workflow |
| `.github/workflows/main.yml` | Scheduled Bitget feed refresh, currently configured for every 10 minutes |
| `services/market-scanner/` | Node.js market-scanner implementation |
| `services/heartbeat/` | Heartbeat service |
| `ecosystem.config.cjs` | Optional PM2 process configuration |
| `manifest/` | Runtime manifest |

The GitHub Action and the optional VM/PM2 runtime are separate execution paths. A committed snapshot does not prove the VM scanner is running, nor does a scheduled workflow guarantee fresh market data.

## Local development

Requires Node.js 20 or newer. Review `.env.example` and use credentials only through local environment variables or your secret store. Never commit the `.env` file.

```sh
git clone https://github.com/Kostazz/piradar-core.git
cd piradar-core
npm install
cp .env.example .env
npm run market
```

For an explicitly configured PM2 deployment, install PM2 separately and review `ecosystem.config.cjs` before starting processes. Do not assume the local run command deploys the application.

## Safety and usage

- Market snapshots are informational and may contain incomplete, outdated, or source-dependent values.
- No promise of profit, financial advice, or guaranteed trading suitability is made.
- Do not store API tokens, wallet secrets, credentials, personal data, or commercial know-how in this public repository.
- Changes to the scheduled publisher must be reviewed for permissions, rate limits, data freshness, and interaction with direct commits to `main`. In particular, a blanket branch protection rule could stop the current workflow that publishes snapshot commits.
- Technical issues can be reported through GitHub Issues. Never include credentials or exploitable secrets in public reports.

## Veřejný feed a GitHub Pages: aktualizace v PR

Bitget ukončil externí V1 API 28. 11. 2025. Dřívější GitHub Actions volaly `/api/spot/v1/market/tickers` a zapisovaly prázdné snapshoty při formálně úspěšném běhu. Nová verze **používá existující spot parser** pro oficiální Bitget V3 `/api/v3/market/tickers?category=SPOT` a kontroluje odpověď, čtyři cílové páry i kladné ceny.

`node scripts/build-public-feed.js` vytváří po úspěchu shodný datový obsah do `out/priceSnapshot.json`, `public/feed/now.json` a `docs/feed/now.json`. Při chybě **ukončí workflow nenulovým kódem bez přepsání posledních ověřených dat**. Pole `close`/`chgUTC` jsou zachována jako kompatibilní aliasy, nový snapshot nese jednoznačný `source`, `status` a `schema_version`.

`docs/index.html` je minimální experimentální veřejná stavová stránka pro stávající GitHub Pages `/docs`, ne hotová aplikace PiRadar ani soukromý dashboard. Stránka označuje snapshot za aktuální jen do 45 minut od ověřeného časového razítka a vyžaduje všechny čtyři páry. Neposkytuje investiční rady ani soukromé informace.

Bez síťových přístupů: `node --test tests/public-feed.test.cjs`. Před merge jsou povinné CI, nezávislé review aktuálního commitu a výslovné schválení změn veřejného feedu a nasazení. Po merge ověřit nový skutečný Actions snapshot **i** úspěšný Pages build; samotné testy nejsou provozní přejímka.
